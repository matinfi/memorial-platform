# آرامگاه مجازی — Test Build

این بسته شامل نسخه تستی قابل نصب برای WordPress است.

- `theme/aramgah-virtual-theme` — پوسته و تجربه scrollytelling
- `plugin/aramgah-virtual` — هسته یادبود، حساب کاربری، ورود/ثبت‌نام، ساخت یادبود و تنظیمات مدیر

برای نصب، فایل ZIP کامل را باز کرده و پوشه‌ها را در `wp-content/themes` و `wp-content/plugins` قرار دهید.
